# Prompt Test Plan for the AI Intent Router

The router is implemented in [AiIntentRouter.php](C:/Users/iryad/Downloads/farmer-ic/app/AI/Services/AiIntentRouter.php).

It classifies a prompt into:

```text
intent
domain
period
topic
confidence
needs_clarification
reason
```

The main intent decisions are:

| Intent | Reason | Typical behavior |
|---|---|---|
| `out_of_scope` | `unsupported_topic` | Returns a deterministic refusal |
| `infographic` | `explicit_visual_request` | Creates a garden, finance, or AI-generated visual |
| `llm` | `finance_analysis` | Uses finance data and may call the LLM |
| `data` | `explicit_data_lookup` | Retrieves application data |
| `llm` | `agriculture_guidance` | Retrieves agricultural knowledge and calls the LLM |
| `llm` | `general_question` | Answers generally or asks for clarification |

The actual route is included in the `message.start` event generated by `AiChatService`. If the interface does not display it, inspect the browser Network tab and open the streaming response for the AI message request.

## 1. Out-of-scope prompts

These should produce:

```text
intent: out_of_scope
domain: general
reason: unsupported_topic
needs_clarification: false
```

Try:

```text
Tolong buatkan kode Python untuk menghitung luas kebun.
```

```text
Bagaimana cara membuat website dengan HTML dan CSS?
```

```text
Bantu saya menulis program JavaScript.
```

```text
Jelaskan strategi investasi crypto untuk saya.
```

```text
Siapa yang akan memenangkan pertandingan sepak bola malam ini?
```

```text
Buatkan query SQL untuk laporan transaksi.
```

Expected behavior:

- The assistant should explain that the topic is outside the Farmer IC assistant’s scope.
- It should redirect the user toward farm data, agriculture, activities, or finance.
- It should not call the language model if `deterministicResponse()` handles the route first.

The relevant terms are defined in:

```php
private const OUT_OF_SCOPE_TERMS = [
    'coding',
    'kode program',
    'python',
    'javascript',
    'html',
    'css',
    'sql',
    'politik',
    'crypto',
    'sepak bola',
];
```

### Important attachment exception

If the same out-of-scope word appears while an image is attached, the router does not immediately classify it as `out_of_scope`.

For example, upload a crop image and send:

```text
Gunakan Python untuk menganalisis foto tanaman ini.
```

Because an attachment exists, the `!$hasAttachments` condition is false. This is useful for checking how vision requests behave.

# 7. Conversation-context routing

The router can reuse the previous assistant message’s domain.

This is handled in `AiChatService`:

```php
$contextDomain = data_get($previousAssistant?->metadata, 'route.domain');
```

Then `AiIntentRouter` receives that context.

Test this as a sequence in the same conversation.

## Sequence A: finance context

First send:

```text
Bagaimana kondisi keuangan bulan ini?
```

Then send:

```text
Tampilkan ringkasannya.
```

The second prompt contains no explicit finance word. Because the previous route was finance and the prompt is short and data-oriented, it may inherit:

```text
domain: finance
```

## Sequence B: garden context

First send:

```text
Bagaimana kondisi Kebun Tani Lestari?
```

Then send:

```text
Buatkan visualnya.
```

The second prompt contains a visual term and can inherit the previous garden domain:

```text
intent: infographic
domain: garden
reason: explicit_visual_request
```

## Sequence C: agriculture context

First send:

```text
Bagaimana cara merawat tanaman jagung?
```

Then send:

```text
Apa langkah berikutnya?
```

The second prompt is short and may inherit:

```text
domain: agronomy
```

This tests whether conversational context helps the router understand follow-up questions.

# 9. Qdrant retrieval and fallback tests

These prompts are useful for checking whether the hosted system actually uses Qdrant.

Try knowledge-heavy questions with distinctive terms:

```text
Bagaimana cara mengatur kelembapan tanah untuk tanaman jagung?
```

```text
Apa langkah pemeriksaan hama pada daun tanaman?
```

```text
Bagaimana prosedur drainase lahan yang terlalu basah?
```

```text
Apa panduan pemupukan untuk tanaman kedelai?
```

In the response metadata, look for fields similar to:

```text
retrieval.retriever: qdrant
retrieval.count: 1 or more
retrieval.evidence_ids
retrieval.scores
retrieval.index_version
embedding_model
```

If Qdrant returns no result, the system may fall back to the in-memory retriever.

Look for:

```text
retrieval.fallback: true
```

or metadata such as:

```text
retrieval_fallback_reason: empty_vector_result
```

To test a likely retrieval miss:

```text
Jelaskan metode pertanian planet Mars dengan sensor gravitasi kuantum.
```

This may still be classified as agriculture because of the word `pertanian`, but it should produce little or no useful evidence. Observe whether the system:

- returns a cautious answer;
- states that the information is unavailable;
- avoids confidently inventing details.

# 10. Citation tests

For prompts that use retrieved knowledge, check whether the final answer contains:

```text
[S1]
```

and a footer such as:

```text
Sumber: ...
```

Try:

```text
Bagaimana cara merawat tanaman jagung yang terkena hama?
```

```text
Apa langkah pemeriksaan penyakit pada daun?
```

```text
Bagaimana cara mengatur irigasi tanaman?
```

The model is instructed to cite evidence as `[S1]`, `[S2]`, and so on.

The validator checks that:

- the citation exists;
- the number is within the evidence range;
- the source footer exists when evidence is present.

The configuration option is:

```php
AI_RAG_REQUIRE_CITATIONS
```

If it is disabled, the system may record citation validation without strictly rejecting an answer.

- the answer identifies the correct period;

The code validates model-generated finance claims using:

```php
$numericValidation = $this->groundedValidator->validateFinance(...)
```

If a model gives an incorrect number, the application can replace the answer with a deterministic finance summary.
